Alphacoeur Serveur : guide de l'administrateur

Dernière mise à jour : 6 novembre 2026

Avec Alphacoeur Serveur, un PC Windows du bureau fait tourner le cerveau d'Alphacoeur pour toute l'équipe. Les iPhone, iPad, Mac, téléphones Android et PC de l'équipe s'y connectent par le Wi‑Fi ou le réseau du bureau. Les conversations restent sur ce PC : rien ne part chez l'éditeur. Pas besoin d'être informaticien : comptez une demi-heure, surtout pour le téléchargement du cerveau.

Sommaire : Ce qu'il faut · Plus de puissance ? · Installer · Activer le mode serveur · S'abonner · Ajouter des appareils · Utilisateurs · Mises à jour · Dépannage

1. Ce qu'il faut

  • Un PC Windows 10 (version 2004 ou plus récente), Windows 11, ou Windows Server 2022 / 2025 avec l'expérience utilisateur (bureau Windows). PC 64 bits (x64).
  • Un PC qui reste allumé pendant les heures de travail, de préférence relié à la box par un câble réseau.
  • Au moins 10 Go de place libre sur le disque.
  • Une connexion Internet pour l'installation (téléchargement du cerveau) et les mises à jour. Les conversations, elles, n'utilisent pas Internet.
  • Un compte administrateur Windows, le temps de l'installation.

Plus de puissance ?

Le cerveau d'Alphacoeur tourne sur l'appareil : sa taille dépend de la mémoire de l'appareil. Plus il y a de mémoire, plus le cerveau est grand, et plus les réponses sont riches et précises. Alphacoeur choisit tout seul le meilleur cerveau qui tient sur l'appareil.

Pour des réponses plus puissantes : installez Alphacoeur sur un ordinateur plus puissant, à la maison ou au bureau, activez le mode serveur, puis connectez-y vos téléphones, tablettes et ordinateurs. Ils profitent alors du grand cerveau de cet ordinateur, par votre réseau local : rien ne part sur Internet.

Conseil : 16 Go de mémoire, et une carte graphique récente si l'équipe dépasse 5 personnes. Le serveur répond à une personne à la fois et met les autres en file d'attente quelques secondes.

2. Installer (double-clic)

  1. Copiez le dossier d'installation d'Alphacoeur sur le PC, puis double-cliquez sur « Installer-Alphacoeur.cmd ». (Avec le Microsoft Store, installez plutôt Alphacoeur depuis le Store, puis lancez l'installateur pour le service serveur s'il vous est fourni.)
  2. Windows demande l'autorisation : répondez Oui. C'est normal, l'installateur en a besoin une fois.
  3. « Ce PC sera-t-il le serveur de l'équipe ? » : Oui. Le serveur démarrera avec Windows, même quand personne n'est connecté, et redémarrera tout seul après une panne.
  4. « Autoriser les appareils du réseau local à joindre le serveur ? » : Oui. Une seule règle est ajoutée au pare-feu de Windows (port 47843, réseau local seulement). Rien n'est ouvert vers Internet.
  5. Ouvrez Alphacoeur : l'assistant « Bienvenue dans l'édition Serveur » vous guide en 4 étapes (bienvenue, abonnement, cerveau, premier appareil). Le cerveau se télécharge tout seul ; vous pouvez continuer pendant ce temps.

2 bis. Activer le mode serveur

Sur quels appareils ? Le mode serveur existe aujourd'hui sur les PC Windows (Windows 10 version 2004 ou plus récent, Windows 11, Windows Server 2022 / 2025 avec l'expérience utilisateur). Mac avec puce Apple : bientôt, dans la même app. Les téléphones et tablettes (iPhone, iPad, Android) ne peuvent pas être serveurs : ils se connectent à un serveur.

Sur l'ordinateur qui sera le serveur :

  1. Ouvrez Alphacoeur › Réglages › Mode serveur, puis touchez « Activer le mode serveur ».
  2. Abonnement : choisissez le palier ; le paiement passe par la boutique (Microsoft Store sur le PC ; sinon « S'abonner depuis mon téléphone »).
  3. Téléchargement du cerveau : le meilleur cerveau pour cet ordinateur se télécharge et s'installe tout seul (taille affichée avant).
  4. QR code : un QR code et un code à 6 chiffres s'affichent pour connecter le premier appareil.

Sur les téléphones, tablettes et autres ordinateurs : Alphacoeur › Réglages › Se connecter à un serveur, sur le même réseau (Wi‑Fi ou câble). Scannez le QR code, ou tapez le code à 6 chiffres et vérifiez que l'empreinte est la même que sur le serveur. Pour se déconnecter : même écran, « Retirer ce serveur » ; l'appareil reprend alors son propre cerveau.

Désactiver le mode serveur : sur le serveur, Réglages › Mode serveur › « Désactiver le mode serveur ». Les appareils connectés reprennent leur propre cerveau. Pensez à résilier l'abonnement dans la boutique ; pour tout effacer du PC (comptes, mémoire, journal) : « Installer-Alphacoeur.cmd /desinstaller /tout ».

3. S'abonner dans l'app

L'abonnement se prend uniquement dans l'app, par une boutique (Microsoft Store, App Store ou Google Play). Il n'y a ni virement, ni facture de l'éditeur, ni clé à acheter ailleurs.

Le prix de votre pays est affiché par la boutique avant l'achat.

  • Sur un PC avec le Microsoft Store : à l'étape « Étape 2 sur 4 : l'abonnement », cliquez sur le palier ; la fenêtre d'achat du Microsoft Store s'ouvre.
  • Sur Windows Server (sans Microsoft Store) : cliquez sur « S'abonner depuis mon téléphone », scannez le code affiché avec Alphacoeur sur votre iPhone, iPad, Mac ou téléphone Android, puis choisissez l'abonnement dans Réglages › Se connecter à un serveur. Le serveur s'active tout seul.
  • Après un achat fait ailleurs, cliquez sur « Actualiser mes achats ».

L'abonnement se renouvelle chaque mois par la boutique. Si le renouvellement n'arrive pas, le serveur continue 7 jours avec un avertissement, puis les appareils reprennent leur propre cerveau. Résilier, changer de palier, obtenir une facture avec TVA : dans la boutique où l'abonnement a été pris (compte Microsoft, compte Apple ou Google Play › Abonnements).

4. Ajouter des appareils

  1. Sur le PC serveur, dans Alphacoeur › Réglages › Mode serveur › Utilisateurs, choisissez la personne (ou créez-la, voir plus bas), puis « Ajouter un appareil ».
  2. Un QR code et un code à 6 chiffres s'affichent. Ils servent une seule fois et pendant 10 minutes.
  3. Sur l'appareil (connecté au même réseau) : Alphacoeur › Réglages › Se connecter à un serveur. Le serveur y apparaît tout seul.
  4. Scannez le QR code, ou tapez le code à 6 chiffres puis vérifiez que l'empreinte affichée sur l'appareil est la même que sur le PC serveur (« Empreinte du certificat »).

C'est tout : l'appareil utilise maintenant le cerveau du serveur. Il se reconnecte seul après une coupure ou une mise à jour.

5. Utilisateurs

  • Ajouter une personne : Utilisateurs › « Nouvelle personne… », tapez son prénom, puis « Afficher le code » pour appairer son premier appareil. Une personne peut avoir plusieurs appareils.
  • Renommer ou Retirer une personne : ses appareils sont déconnectés et sa mémoire est effacée du serveur.
  • Appareil perdu ou remplacé : « Retirer l'appareil » sur la ligne de la personne.
  • Le nombre de personnes est limité par le palier (« utilisateurs sur … permis par la licence »).
  • Chaque personne a sa propre mémoire, chiffrée sur le serveur, que les autres ne voient pas. Le journal du serveur note qui se connecte et quand, jamais le contenu des messages.

6. Mises à jour

  • Le serveur vérifie les mises à jour quelques minutes après le démarrage puis toutes les 6 heures, et les installe tout seul. Les réponses en cours se terminent d'abord ; les appareils patientent quelques secondes et se reconnectent seuls.
  • Si une nouvelle version ne démarre pas, le serveur revient tout seul à la précédente.
  • Comptes, mémoire, abonnement et appairages sont gardés : rien à refaire sur les appareils.
  • Paliers Équipe et Entreprise : « Options avancées › Canal des mises à jour › Anticipé (avant-première) » pour recevoir les versions et les cerveaux en avance. « Stable » convient à la plupart des bureaux.
  • Les mises à jour sont signées par l'éditeur ; le serveur refuse tout paquet dont la signature ne correspond pas.

7. Dépannage

Un appareil ne trouve pas le serveur

  • Le PC serveur est-il allumé, et pas en veille ? (Paramètres › Système › Alimentation : mise en veille « Jamais » sur secteur.)
  • L'appareil est-il sur le même réseau que le serveur ? Un Wi‑Fi « invités » isole les appareils : il ne marche pas.
  • Utilisez le QR code plutôt que le code à 6 chiffres : il contient l'adresse du serveur, même quand le réseau bloque la découverte automatique.
  • Sur iPhone, iPad ou Mac, autorisez « Réseau local » pour Alphacoeur ; sur Android, « Appareils à proximité ».

Pare-feu

  • L'installateur crée la règle « Alphacoeur Serveur (réseau local) » : port 47843 (TCP), réseau local seulement. Si vous avez répondu Non, relancez « Installer-Alphacoeur.cmd ».
  • Dans Paramètres › Réseau et Internet, le réseau du PC serveur doit être un réseau privé, pas public.
  • Un antivirus avec son propre pare-feu peut bloquer le serveur : autorisez le port 47843 (TCP) pour le réseau local.
  • « Le serveur n'a pas pu démarrer : son port est déjà utilisé » : le service tourne sans doute déjà ; redémarrez le PC.

Wi‑Fi

  • Les répéteurs et le Wi‑Fi maillé conviennent, tant que tout est sur le même réseau.
  • Si le serveur change d'adresse (box remplacée), les appareils le retrouvent seuls ; sinon, ré-appairez avec un nouveau QR code.

Utiliser le serveur hors du bureau : VPN

Le serveur refuse les connexions venant d'Internet. N'ouvrez jamais le port 47843 sur la box : cela ne marcherait pas et exposerait le PC. Pour l'utiliser en déplacement ou en télétravail, passez par un VPN :

  • Tailscale (le plus simple) : installez-le sur le serveur et sur les appareils, avec le même compte. Si Tailscale tourne quand vous affichez le QR code, l'adresse VPN y est incluse.
  • WireGuard (sur la box ou un PC du bureau) : si ses adresses sont dans un autre sous-réseau privé, ajoutez ce sous-réseau à la règle de pare-feu « Alphacoeur Serveur (réseau local) ».

Réponses lentes

  • Plusieurs personnes à la fois : chacune attend son tour (« File d'attente » sur l'écran du serveur).
  • PC sans carte graphique : un cerveau plus petit ou plus lent est choisi. Ajouter de la mémoire ou une carte graphique permet un meilleur cerveau.

Désinstaller

Installer-Alphacoeur.cmd /desinstaller retire l'app et le service ; ajoutez /tout pour effacer aussi les données du serveur (comptes, mémoire, journal). Résiliez l'abonnement dans la boutique.

Urgences : Alphacoeur donne des repères généraux et peut afficher les numéros d'urgence, mais n'appelle personne et ne remplace ni un médecin ni les secours. En cas d'urgence, appelez le 15 ou le 112.

Alphacoeur Server: administrator guide

Last updated: November 6, 2026

With Alphacoeur Server, a Windows PC at the office runs Alphacoeur's brain for the whole team. The team's iPhones, iPads, Macs, Android phones and PCs connect to it over the office Wi‑Fi or network. Conversations stay on that PC: nothing goes to the publisher. No IT skills needed: allow about half an hour, mostly for the brain download.

Contents: Requirements · More power? · Install · Turn on server mode · Subscribe · Add devices · Users · Updates · Troubleshooting

1. Requirements

  • A PC running Windows 10 (version 2004 or later), Windows 11, or Windows Server 2022 / 2025 with Desktop Experience. 64-bit PC (x64).
  • A PC that stays on during working hours, ideally connected to the router with a network cable.
  • At least 10 GB of free disk space.
  • An Internet connection for installation (brain download) and updates. Conversations themselves do not use the Internet.
  • A Windows administrator account, for the installation.

More power?

Alphacoeur's brain runs on the device: its size depends on the device's memory. The more memory, the bigger the brain, and the richer and more accurate the answers. Alphacoeur picks the best brain that fits on the device on its own.

For more powerful answers: install Alphacoeur on a more powerful computer, at home or at the office, turn on server mode, then connect your phones, tablets and computers to it. They then use that computer's big brain, over your local network: nothing goes to the Internet.

Indicative guide: the exact choice also depends on the graphics card, free disk space and the brains available in the catalog at installation time.

To see the PC's memory: Settings › System › About (“Installed RAM”).

Tip: 16 GB of memory, and a recent graphics card if the team has more than 5 people. The server answers one person at a time and queues the others for a few seconds.

2. Install (double-click)

  1. Copy the Alphacoeur installation folder to the PC, then double-click “Installer-Alphacoeur.cmd”. (With the Microsoft Store, install Alphacoeur from the Store instead, then run the installer for the server service if one was provided.)
  2. Windows asks for permission: answer Yes. This is normal; the installer needs it once.
  3. “Will this PC be the team server?”: Yes. The server will start with Windows, even when nobody is signed in, and restart on its own after a failure.
  4. “Allow devices on the local network to reach the server?”: Yes. A single rule is added to Windows Firewall (port 47843, local network only). Nothing is opened to the Internet.
  5. Open Alphacoeur: the “Welcome to the Server edition” assistant guides you in 4 steps (welcome, subscription, brain, first device). The brain downloads on its own; you can carry on meanwhile.

2b. Turning on server mode

On which devices? Server mode is available today on Windows PCs (Windows 10 version 2004 or later, Windows 11, Windows Server 2022 / 2025 with Desktop Experience). Mac with Apple silicon: coming soon, in the same app. Phones and tablets (iPhone, iPad, Android) cannot be servers: they connect to a server.

On the computer that will be the server:

  1. Open Alphacoeur › Settings › Server mode, then tap “Turn on server mode”.
  2. Subscription: pick the tier; payment goes through the store (Microsoft Store on the PC; otherwise “Subscribe from my phone”).
  3. Brain download: the best brain for this computer downloads and installs on its own (size shown first).
  4. QR code: a QR code and a 6-digit code appear to connect the first device.

On phones, tablets and other computers: Alphacoeur › Settings › Connect to a server, on the same network (Wi‑Fi or cable). Scan the QR code, or type the 6-digit code and check that the fingerprint matches the one on the server. To disconnect: same screen, “Remove this server”; the device then goes back to its own brain.

Turning server mode off: on the server, Settings › Server mode › “Turn off server mode”. Connected devices go back to their own brain. Remember to cancel the subscription in the store; to erase everything from the PC (accounts, memory, log): “Installer-Alphacoeur.cmd /desinstaller /tout”.

3. Subscribe in the app

The subscription is taken only in the app, through a store (Microsoft Store, App Store or Google Play). There is no bank transfer, no invoice from the publisher and no key to buy elsewhere.

The price for your country is shown by the store before you buy.

  • On a PC with the Microsoft Store: at the subscription step (step 2 of 4), click the tier; the Microsoft Store purchase window opens.
  • On Windows Server (no Microsoft Store): click “Subscribe from my phone”, scan the code shown with Alphacoeur on your iPhone, iPad, Mac or Android phone, then choose the subscription in Settings › Connect to a server. The server activates on its own.
  • After a purchase made elsewhere, click “Refresh my purchases”.

The subscription renews every month through the store. If the renewal doesn't arrive, the server keeps going for 7 days with a warning, then devices go back to their own brain. Cancel, change tier, get a VAT invoice: in the store where the subscription was taken (Microsoft account, Apple Account or Google Play › Subscriptions).

4. Add devices

  1. On the server PC, in Alphacoeur › Settings › Server mode › Users, pick the person (or create them, see below), then “Add a device”.
  2. A QR code and a 6-digit code appear. They work once, for 10 minutes.
  3. On the device (connected to the same network): Alphacoeur › Settings › Connect to a server. The server shows up on its own.
  4. Scan the QR code, or type the 6-digit code and check that the fingerprint shown on the device matches the one on the server PC (“Certificate fingerprint”).

That's it: the device now uses the server's brain. It reconnects on its own after an outage or an update.

5. Users

  • Add a person: Users › “New person…”, type their first name, then “Show code” to pair their first device. A person can have several devices.
  • Rename or Remove a person: their devices are disconnected and their memory is erased from the server.
  • Lost or replaced device: “Remove device” on the person's row.
  • The number of people is limited by the tier (“users out of … allowed by the licence”).
  • Each person has their own memory, encrypted on the server, that others can't see. The server log records who connects and when, never the content of messages.

6. Updates

  • The server checks for updates a few minutes after starting and then every 6 hours, and installs them on its own. Answers in progress finish first; devices wait a few seconds and reconnect on their own.
  • If a new version doesn't start, the server goes back to the previous one on its own.
  • Accounts, memory, subscription and pairings are kept: nothing to redo on the devices.
  • Team and Business tiers: “Advanced options › Update channel › Early access” to get versions and brains ahead of time. “Stable” suits most offices.
  • Updates are signed by the publisher; the server refuses any package whose signature doesn't match.

7. Troubleshooting

A device can't find the server

  • Is the server PC on, and not asleep? (Settings › System › Power: sleep “Never” when plugged in.)
  • Is the device on the same network as the server? A “guest” Wi‑Fi isolates devices: it won't work.
  • Use the QR code rather than the 6-digit code: it contains the server's address, even when the network blocks automatic discovery.
  • On iPhone, iPad or Mac, allow “Local Network” for Alphacoeur; on Android, “Nearby devices”.

Firewall

  • The installer creates the rule “Alphacoeur Serveur (réseau local)”: port 47843 (TCP), local network only. If you answered No, run “Installer-Alphacoeur.cmd” again.
  • In Settings › Network & Internet, the server PC's network must be a private network, not public.
  • An antivirus with its own firewall may block the server: allow port 47843 (TCP) for the local network.
  • “The server could not start: its port is already in use”: the service is probably already running; restart the PC.

Wi‑Fi

  • Repeaters and mesh Wi‑Fi are fine, as long as everything is on the same network.
  • If the server's address changes (new router), devices find it again on their own; otherwise, pair again with a new QR code.

Using the server away from the office: VPN

The server refuses connections from the Internet. Never open port 47843 on your router: it wouldn't work and would expose the PC. To use it while travelling or working from home, go through a VPN:

  • Tailscale (the simplest): install it on the server and on the devices, with the same account. If Tailscale is running when you show the QR code, the VPN address is included in it.
  • WireGuard (on the router or an office PC): if its addresses are in another private subnet, add that subnet to the firewall rule “Alphacoeur Serveur (réseau local)”.

Slow answers

  • Several people at once: each waits their turn (“Queue” on the server screen).
  • PC without a graphics card: a smaller or slower brain is picked. More memory or a graphics card allows a better brain.

Uninstall

Installer-Alphacoeur.cmd /desinstaller removes the app and the service; add /tout to also erase the server's data (accounts, memory, log). Cancel the subscription in the store.

Emergencies: Alphacoeur gives general pointers and can display emergency numbers, but never calls anyone and does not replace a doctor or emergency services. In an emergency, call your local emergency number (112 in Europe).
